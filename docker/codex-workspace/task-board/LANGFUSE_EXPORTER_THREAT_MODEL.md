## Guaranteed

- K0 withholds the fixed source table: environment, SSH, cloud and CLI credential files, kubeconfig, private-key extensions and token files (any word ending in `token`, a `tokens` word with a suffix or extension, or a `tokens` path element; a bare plural such as `max_output_tokens` is a counter word); and the listed AWS, gcloud, Azure, kubectl, oc, Vault, 1Password, Docker, Helm, Git and environment-dump commands. The first reason propagates to later bodies and the session lineage, including later results that a known-format mask would otherwise let through.
- K1 masks provider keys, AWS and Google keys, Telegram values, JWTs, bearer and header values, URL credentials, private keys, secret-name assignments, environment entries and values, flags, CLI passwords and XML elements. Lines with a secret word and their neighbours are masked.
- Lineage withhold after a tool result (`known_format_in_tool_output`) is triggered only by shapes that are credentials by themselves: private keys, Authorization/Cookie headers, URL credentials, JWTs, bearer values, provider/AWS/Google/Telegram keys, and the exporter's own environment values. Name-based hits (secret-name assignments, environment entries, flags, CLI passwords, XML elements) mask the value in place and do not withhold what follows: they also match ordinary code and logs such as `TOKEN_FILE=/work/x`, `token = os.environ[...]` or `credentials: 'same-origin'`, which withheld whole runs in production (BOXP-428, 2026-11-07). A model restating such a masked value elsewhere is the accepted residual below.
- The queue and spool receive masked, final-guarded spans. Scan failures and tool outputs over 1 MiB fail closed.

## Not guaranteed (accepted residual, Owner decision)

Plain values without a secret word or format nearby; a model repeating a value far from its source, including a value that a name-based mask hid in the tool result; unknown transforms; arbitrary shell spellings of the same command; and secrets in the Owner's request without a format.
