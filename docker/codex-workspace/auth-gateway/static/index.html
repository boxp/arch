AI CLI 本人ログイン

codex-workspace の公式 CLI に、ご本人がログインするためのページです。認可コードやURLはこの画面の中だけで扱い、保存・記録しません。

1. ログインする CLI を選ぶ

手順
  • Antigravity: 「1. Google OAuth」で Enter → 下の「リンク」を開いて本人の Google アカウントでログイン → 表示された認可コードを「貼り付け欄」から送信して Enter。ログイン後に「Done」等の選択が出たら →/↓ ボタンで選んで Enter。その後 /config で「Use AI Credits」が off であることを確認し、「セッション終了」。
  • Claude Code: 「リンク」を開いてサブスクリプションのアカウントでログイン → 表示されたコードを貼り付け欄から送信して Enter。完了すると自動で終了します。
  • Codex: 「リンク」を開き、画面に出たワンタイムコードを入力（ChatGPT 側でデバイスコード認証の許可が必要な場合があります）。完了すると自動で終了します。
  • Grok: 「リンク」を開き、本人の grok.com（xAI）アカウントでログインして、画面に出たコードと同じか確認して承認します。完了すると自動で終了します。ログイン情報はコハコの X 読み取り専用の置き場に保存され、他の CLI とは分けられます。下の「状態を確認」には出ません（成否は次の確認実行で判断します）。

2. 公式ログイン画面

リンク（タップで別タブ。ログイン後この画面に戻ってください）:

    スマホのキーボードに無い矢印・Tab などはここから送れます（例: 「Done」へ移るには →、決定は Enter）。

    3. ログイン状態の確認（ログイン操作とは別）

    CLI保存状態補足

    ここで分かるのは保存された認証の非秘密メタデータだけです。「ok」でも実際の利用成功を意味しません（次の実行で確認されます）。Antigravity は資格情報を読まない契約のため、直近の実行結果だけを表示します。
