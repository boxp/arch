## 実測と変更

## 目尻の被り

v11g の layout から顔・目に前髪と横髪をそれぞれ追加した単独合成では、画面右の目尻を覆う暗い部分は `hair_front` であり、`hair_side_left` 単独では同じ被りは発生しない（`layers.jpg`）。前髪の alpha と開眼まつ毛の重複部分だけを仮に抜くと、開眼では目尻が露出するが、閉眼では髪の中に背景が露出する（`mask-test.jpg`、白背景の静止合成）。これは試験でありモデルには適用していない。髪が動く際の固定マスクの副作用も避けるため被りは残した。顔層にも元の目尻近傍の暗い描線があり、適切な動的分割は今後の課題。

## Chromium 評価

実 Chromium / SwiftShader、DPR 2、upper、behaviors 停止。同一虹彩基準で登録した `static.jpg` / `grid.jpg` は原画 v0 / v11e / v11g / v11h、静止上半身も併記。`eye.jpg` は目 1→0 を 0.05 刻み、`mouth.jpg` は口 0→1、`cheeks.jpg` は AngleX ±20 / AngleZ ±10、`poses.jpg` は v11g / v11h の 9 姿勢マゼンタ比較。`pair.mp4` は左 v11g / 右 v11h の同一パラメータ軌道、20 秒 / 10 fps。静止撮影による軌道であり、自動 Blink や実時間の物理の検証ではない。

目の連続状態では既存の 0.85〜0.60 付近の点線、0.60 の灰色の重なり、0.15→0.10 の急な切替が残る。新たな大きな半眼・閉眼位置ずれや顔下地の継ぎ目はシート上では見えないが、微細な境界の不存在は未確定。画面右の目尻の被りは残る。

頭部 ROI (device pixel x=280..559, y=60..399) で v11h がほぼ純マゼンタかつ v11g が非マゼンタの画素数は rest / idle4 / idle10 / X− / X＋ / Z− / Z＋ / BodyX− / BodyX＋ = **0 / 9 / 4 / 2 / 0 / 13 / 5 / 4 / 3**。大きな新規穴は比較画像で見えないが、少数の増加があるため新規露出ゼロとは断定できない。既存の髪脇の露出も残り、全角度・実 GPU は未検証。

自己評価: 原画と v11g の差は一様な目の縮小ではなく、横幅・高さ・まつ毛形状が左右で異なる。v11h の右開口は少し広がったが、変化は小さく、虹彩とまつ毛が原画より大きい部分もある。顔全体は同じキャラクターを意識した近い印象だが、原画の目尻、まつ毛形状、顔幅と鼻・口の線の差が残り、同一人物に見えると断定できない。未受入のまま最終判断を委ねる。
