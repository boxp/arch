# kohako-v37: 顔の横の髪が顔と無関係に動く原因（体の層に残っていた頭の髪）を修正（BOXP-441 TD-27、固定 URL 最新試作）

**今回の画像生成 0 回**（髪枠は 2026-11-07 04:02Z の肩/衣装下地 1/4 のみ使用済みのまま）。公式 Cubism Core 不使用。素材は v36 と同じ。

## v36 の判断の撤回
v36（TD-26）は「後ろ髪のメッシュ頂点（縦 6 帯の平均）が顔に追従している」ことで合格としたが、Owner は v36 でも
「後ろ髪が顔と無関係に動く」と再指摘した。頂点の平均だけでは、**実際に見えている画素がどの層のものか**を見ておらず、識別力が無かった。

## 再現と原因（配備 v36、`verify/td27/`）
- 層単独描画（`layers.mjs`: 指定 mesh 以外の `drawMesh` を skip）で、体の層（`ArtMeshTopwear`）に **頭頂の外周と顔の横の髪（顎 y≈345 まで）が焼き込まれたまま**だと判明（`compare/kohako-v37-cause-v36-layers.jpg`）。
  描画順は 後ろ髪 < 体 < 顔 < 前髪 なので、頭に追従する後ろ髪の上部はこの体の髪の裏に隠れていた。
- その結果、首を振ると顔・前髪・三つ編み・外側の長い髪は頭と一緒に動くのに、顔のすぐ横の髪は体と一緒に止まり、互いにすべって
  「髪が顔と無関係に動く」ように見えていた。首を傾けると頭頂の裏地（黒い塊）や白い欠けも露出した（`compare/kohako-v37-tilt-vs-v36.jpg`）。
- もう一つの原因: psd2live は肩・腰の線を体の層のメッシュ範囲から推定する（`Analyzer.anchorsFor`: shoulderY = topwear.top + 12%）。
  体の層に頭髪があったため肩の線が頭の中（y≈92）になり、体の回転 ParamBodyAngleX ±10 で顔が ±35px（肩より大きく）振れていた。
- 計測（`track.mjs`）: 同じ画角で A 顔だけ（AngleX/Y/Z）、B 顔を固定して髪の物理・呼吸・体の回転だけ、C 通常の待機・考え中・発話、を録画し、
  毎 frame の最終描画時点の parameter と、顔メッシュに当てはめた相似変換（回転+拡縮+平行移動）で予測した位置からの、顔の横の髪の頂点のずれを記録。
  v36 では顔の横に見える髪（体の層）が 最大 10〜40px ずれていた（AngleZ ±10 で 24〜38px、AngleX ±20 で 11〜20px、通常動作で 8〜25px）。

## 修正
1. `move_headhair.py`（`kohako-v35/fix_gaps.py` の後）: 体の層の顎より上（y < 345、首の柱を除く）の不透明画素 41,757px と、
   側面の幅 5px 未満の暗い髪の輪郭 1,488px を、同じキャンバス位置のまま後ろ髪の層へ重ね（over 合成）、体から消す。静止時の見た目は変わらない。
   後ろ髪の顎より上は v36 の backhair-anchor で頭に剛体追従する。
2. `patch_body.py`（`P2L_BACKHAIR_BODY=1` のときだけ有効）: 体の層が正しい範囲になると肩の線も正しくなり、体の回転で首はほぼ動かない（psd2live 本来の動き）。
   後ろ髪は頭の子なので、肩より下の長い髪が胴の回転に付いてこなくなる。後ろ髪の追従ワープに ParamBodyAngleX 軸を足し、肩より下の行（v36 と同じ smoothstep）へ
   その点での胴の回転変位（`BodyStance.bodyPoint`）から頭の支点の変位を引いた分を加える。
   （移した画素を体の層に alpha 8 で残して範囲を保つ案も試したが、psd2live はメッシュ範囲から推定するため効果が無く、`GHOST=0` を既定にした。）
