## 実 Web の比較と残件

実 Chromium / SwiftShader、DPR 2、upper、behaviors 停止。同じ目基準で正規化した `static.jpg` と `grid.jpg` は原画 v0 / v10k / v11e / v11g、静止上半身も併記。前髪が画面右側の目尻に重なり、原画との差が見え方に影響する。間隔は原画に近づいたが、まつ毛と目の形、鼻と口線の描線、顔幅の印象はまだ異なり、同じ人物に見えるかは担当の判断が必要。数値の一致のみで受入とはしない。

`eye.jpg` は両目 1→0、`mouth.jpg` は口 0→1、いずれも 0.05 刻みの実 Web キャプチャ。v11e 由来の 0.60 付近の灰色の重なり、0.15→0.10 の急な切替、開口の小ささは残る。下まぶたの点線も残る。`cheeks.jpg` は AngleX ±20 / AngleZ ±10、`poses.jpg` は v11e / v11g の 9 姿勢マゼンタ背景比較。`pair.mp4` は左 v11e、右 v11g、同じパラメータ軌道の 20 秒 / 10 fps、瞬きと口・角度を含む。原画は静止画のため動画には含めない。再生は実時間の物理・自動 Blink ではなく、同じ指定軌道のフレーム撮影。

頭部 ROI (device pixel x=280..559, y=60..399) で v11g がほぼ純マゼンタかつ v11e が非マゼンタの画素数は rest / idle4 / idle10 / X− / X＋ / Z− / Z＋ / BodyX− / BodyX＋ = **0 / 57 / 21 / 66 / 39 / 156 / 10 / 7 / 12**。Z− の差分は髪の外周や既存の髪脇の隙間の縁に沿う細い領域が大半で、最大の連結成分は 2×37 px、45 px。新規露出ゼロは証明できず、再生成 rig の境界差と実際の隙間拡大の厳密な切り分けは未完。大きな新規穴は比較画像では見えないが、前版由来の髪脇の露出は残る。実 GPU や全角度・全動作は未検証。
