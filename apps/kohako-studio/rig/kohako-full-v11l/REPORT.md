# BOXP-441 TD-46〜48: kohako-full-v11l

本人受入済みの顔配置（v11g / v11j / v11k）を保持し、本人指摘の口（げっ歯類様・口周りが細い）、前髪のゴミ、後ろ髪のゴミ（手の後ろ）を直した試作。全身の美術受入前。画像生成、Gemini、外部画像 API、Core 取得は行っていない（頭部キット枠は 3/5 のまま）。

## 手順

`rig/kohako-full-v11k` の layout コピーに `prepare_v11l.py` を適用（`LAYOUT`、`V10K`=v45 の口が残る v10k layout、`V11J`=v11j layout、`ART`=kohako-full-art-v0 の JPEG）し、`build.sh` に渡す。出力 p2lrt の SHA-256: `959ba40ed59a27a547632700ca38c05ebe70e4f0da3981011205f90a7e636a20`。

## 原因と修正

- **口（TD-46）**: v11 系の頭部キットの口は、開口時の幅が虹彩間隔の 0.36 倍と狭く（v45 は 0.47 倍）、暗い V 字で閉じるためげっ歯類様に見えていた。v10k layout に残る v45 の口画素（`mouth_open` 47x19、閉口線 `face_smile`）と v25/v45 の不透明度キー（閉口線 0→1,0.08→0 / 開口 0→0,0.08→1）へ戻し、3 段の口層を外した。開閉の変形は生成器の口メッシュに任せる（v45 と同じ）。顔の配置は変えていない。
- **前髪のゴミ（TD-47）**: 前髪の隙間に見える白い点線は、顔層の髪部分に残った点と、後ろ髪下地の肌色片。顔層の点を局所補完し、下地の肌色片を髪色へ。頭頂左の段差は、移植した前髪の輪郭を原画の輪郭へフェードし、花の脇の切れ込みを髪色で塞いだ。キャラ左の頬横の房は内縁を滑らかなマスクにし、顔層の折れた髪線を肌へ置換した。正当な前髪の線・髪飾りは残している。
- **後ろ髪のゴミ（TD-48）**: 手の後ろのゴミは 2 種類。(1) 細い毛束のマスクが二値で途切れ、白い切れ端とともに点状に残っていた → 肩より下の背景接触部の alpha を原画から再抽出（`rematte`）し、細い毛束は柔らかい線に作り直し。(2) 後ろ髪層に原画の手袋・袖口・指先の画素が焼き込まれ、体が回ると本体から離れて浮いていた。v11k の下層延長（26 px）も手の周りで黒い塊になっていた → 腕・手の裏の後ろ髪は腕の 8 px 内側で止め、その帯は近傍の髪色で塗り、腕・手の延長は 8 px に制限。指先は手の層に載せ直し、手の層の矩形を拡張した。

## 確認（実 Chromium、配備版ページに候補 p2lrt を差替え）

`compare/kohako-full-v11l-*` に、原画 / v11k / v11l の頭部比較、口の開閉（v11k / v11l / 参照 v45）、手の周り（静止と体 +5）、自然動作 23 秒の同時刻動画（全身・顔拡大）を置いた。口の形は v45 と一致。手の周りの黒い塊と浮いた断片は消えた。v11k の改善（髪の欠け、まばたき）に退行は見えていない。
