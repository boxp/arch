# BOXP-470: kohako-full-v11n

v11m に対する Owner の所見（後ろ髪の隙間、スカートの切れ目、太もものずれ）を、生成なしで層とレイアウトから直した版。顔・口・表情のパーツと `build.py` は v11m のままで、変更は `prepare_v11n.py` の層の加工だけ。画像生成、Gemini、外部画像 API は使っていない。

## 手順

`rig/kohako-full-v11m` の出力 layout のコピーに `prepare_v11n.py` を適用し（`LAYOUT`、`ART`=kohako-full-art-v0 の JPEG）、`build.sh` に渡す。`P2L` は `kohako-full-v10k/anchor.patch` を適用済みのツリーを使う。出力 p2lrt の SHA-256: `0e4b6f1b253e9fd8c9f224977b7f414d681dc2eae264f57c44a324c372cfa882`。`seed-Idle` / `seed-Talk` の失敗は v11g 以降と同じ扱い。

## 原因（層単独の描画と `meshVertices` の実測）

通常動作の実測範囲は体 X ±4.6、体 Z ±3、頭 X ±15、頭 Z ±6（以前の ±3.5 は過小だった）。体 X +5 で後ろ髪は腕より約 12 px 余計に動く。

| 症状 | 原因 |
|---|---|
| 後ろ髪の隙間 | 肩より下の `back_hair` が、腕とパネルを抜いた跡の穴、階段状の切れ端、暗い穴埋めの塊の継ぎはぎだった。静止時は腕で隠れ、揺れると見えていた |
| スカートの切れ目 | パネル外側の紫金の帯が `back_hair` にだけ存在し、体を回すとパネルの外へはみ出してずれた |
| 太もものずれ | パネル層の内側に脚の絵の楔が混じってパネルと一緒に動き、水色の線が折れていた。加えて胴の層が y=1016 の直線で終わり、体 X +5 で胴下端 +11.9〜16.9 px、脚上端 +10.2〜10.8 px と動きが違うため段差が見えた |

## 修正

1. 肩より下の `back_hair` を原画から作り直す。腕とパネルの裏へ髪を連続させ、閉じた隙間は埋める。外へ開いた毛束の隙間は原画のまま残す。
2. `back_hair` にしかなかったパネル外側の帯を原画からパネル層へ戻す。
3. パネル層の脚の楔を脚の層へ移す（内側の線は行ごとに検出して曲線で近似）。下に脚や胴が無い箇所は隙間を避けるためパネルに残す。
4. 胴の下端 y 984〜1016 を脚へフェードする。パネルに隠れる脚の部分は水色の線を含まない色で塗り直す。
5. 腕・手・パネルの浮いた小片を除く。

## 確認（実 Chromium / SwiftShader）

- `compare/kohako-full-v11n-pair.mp4`（全身）/ `-body.mp4`（胴の拡大）: 同一軌道（体 X ±5、体 Z ±3、頭 X ±15、頭 Z ±6、固定刻みの物理）8 秒の左 v11m / 右 v11n。
- `compare/kohako-full-v11n-hair.jpg` / `-skirt.jpg` / `-thigh.jpg`: 同一フレーム（25/75/125）の比較。
- 腕の左右の帯で、人型の内側に閉じた背景露出: v11m 平均 3136 px / 最大 3926 → v11n 平均 1602 / 最大 1834（160 フレーム）。20 px 以上の隙間の数は 27.4 → 16.1。残りは主に原画にある毛束の間の隙間。
- 静止の v11m との差の平均は 0.61（0〜255）。頭頂と顔（y<470）は静止で 0.03 で、顔・口のパーツは変更していない。

## 未確認・残件

- 実機 GPU と本人ブラウザでの見え方（SwiftShader のソフト描画のみ）。本人の美術評価。
- 肩より下の長い髪は層の形が変わったため、頭を傾けたときの動きが v11m と少し違う。顔まわりの髪の差はほぼ無い。
- 体 ±10 度（通常動作の外）では腕の下の髪に小さな欠けが残る。毛束の間の細い線はごく細かい点線に見える箇所がある。
