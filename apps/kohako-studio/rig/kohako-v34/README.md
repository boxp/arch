（body は約19.5万画素が白のままだった）。見た目の画素は変わらない。

- 評価: 点線は v30 と同じ → 不採用。web の p2l.js はテクスチャを premultiplied で読み込むため、透明画素の白のにじみは原因ではないと判断。

## 点線の切り分け結果（v31〜v34）
body 層の低 alpha ゴースト除去(v31)、後ろ髪内部の明るい画素補正(v32)、髪の縁の白にじみ除去(v33)、透明画素の色埋め(v34)
はいずれも効果なし。描画側の候補として、テクスチャの縮小がミップマップなしの LINEAR であること、
オフスクリーン描画先が NEAREST で合成されること（p2l.js）が残る。録画道具に `DSF`（画面倍率）指定を追加したが、
screencast は CSS 解像度で記録されるため倍率 2 の比較は決定的でなかった。
