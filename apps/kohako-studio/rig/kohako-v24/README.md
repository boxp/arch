# kohako-v24

v23 の髪分割を維持し、画像生成なしで 3 点を直した試作です。`rebuild.sh` が v23 の後に実行します。

| ファイル | 役割 |
|---|---|
| `create_parts.py` | v23 の layout を複製し、`mouth_closed`・`mouth_half` 層を外して `orn_fix.py` を呼ぶ |
| `orn_fix.py` | 前髪層の桜飾り（ピンク画素、canvas x 230〜335 / y 30〜215）の形で塗られていた `body`・`hair_back` の髪色下地を、体＋前髪の暗い画素を大きくクロージングして推定した頭の輪郭の外側だけ透明にする。三つ編み下の体側の淡い補完も同じ輪郭規則で整理する |
| `eyes.py` | まぶた変形 1→EPS、EPS 以下は生成閉眼パッチ（`V24_EYE_EPS`、既定 0.15） |
| `capture.py` | 口 0〜1、目 1〜0、9 ポーズの静止比較シート |

## 根拠（TD-21 / TD-22）

- 口の二重線: psd2live の口テンプレートは `MOUTH_CLOSE` 層を自前の切替規則で中開度まで表示し続けるため、v6〜v22 で `keyform_apply` した不透明度キー（全キー 0 にしても描画不変）は効いていなかった。開口 1 枚だけにすると生成器のメッシュ変形で 0→1 が連続する。
- 髪飾り: v1 で桜飾りを前髪層へ切り出した際、その形のまま髪色で塗られた下地が `body` と `hair_back` に残り、首振りで髪飾りの左に黒い花形が露出していた（Owner 指摘）。
- 目: 不透明度の長い交差（0〜0.35）が「急な切替」「二重弧」の原因。テンプレートのまぶた変形は 0.15 まで自然に閉じるので、それ以下だけパッチに切り替える。
