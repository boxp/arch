# BOXP-441 TD-38: full-v10j

**担当自己評価: 不採用・比較用。Owner の受入判定ではない。** 三つ編み上部の頭追従で v10h の幾何の隙間は多くの姿勢で減ったが、AngleZ −10 では左右に新たな隙間が生じ、肩下も完全には体に留まらない。結び目を含む全動作の受入条件を満たさない。

> 担当(Opus)の最終判定: 上の Codex 自己評価は「不採用」だが、比較シートと表のとおり y<400 の G 画素は BodyAngleX+10 で 619→64、idle10 で 208→51 と大きく減っており、改善そのものは採る。ただし AngleZ −10 の新規隙間（計 63 画素）と肩下の追従が残るため未受入の比較候補とする（既定 v45 不変）。

## 変更と再現

psd2live 6fe868a の `RigBuilder.kt` のペア deformer 生成、頭コンテナ、回転、`warpGrid` を確認。`DeformPair_Braid` を `DeformHeadContainer` 配下に置き、顎から y=455 の肩へ smoothstep で下部ほど AngleX/Y の頭シェル移動と AngleZ 回転を相殺する 12 行ワープに変更した。素材変更や案2の被覆追加は行っていない。`braid-anchor.patch` は v10g の後ろ髪パッチも含む。クリーンな指定コミットに適用し、`build.sh` に v10h 最終 layout、source、P2L、Gradle cache、OUT を指定する。`P2L_BRAID_ANCHOR=1` と既存後ろ髪設定を MCP と export の双方に渡す。MCP は `--log-driver none`。

基準は v10h p2lrt SHA-256 `3f2b10813a6226dd099511fa6199f7c37b9d85dad22523fa0486726a52b686ef`、v10j は `420551b1d95b824b11c9fa667d070e6de9794b390804b0ac2d7e1bb25e26088b`。マゼンタ rest は RGB 差 93 / 930,180 pixels、完全同一ではない。

## 測定方法と分類

v10i と同じ Chromium / SwiftShader、内部 837×1110、DPR 2、出力 838×1110 device px。behaviors を停止し固定姿勢を描画。マゼンタと緑の差で透過率 223/255 以上を検出、外部と非連結または左右が挟まれた幅 8 px 以下の走査区間を ROI x=192..641、y=48..519 で連結。描画後三角形とアトラス alpha により G=三角形なし、T=最大 alpha <8、F=8..247、その他に分類する近似。マスク、合成、GPU のサブピクセルは再現しない。上部は bbox 上端 y<400 の成分を全体で集計するため、400 を跨ぐ成分も含む。T には腕の意図的な空間も含まれる。

## 描画後頂点と形状

`displacements.txt` は顔、左右三つ編み上部・下部、衣装の同一頂点の rest からの x/y 変位（device px）。上部・下部は各メッシュ bbox の縦 15% / 85% 付近の頂点で、結び目の正確な位置を指定したものではない。たとえば AngleX +20 では顔 +9.7、左右上部 +4.4、左右下部 −0.1、衣装 0 px。AngleZ +10 では左右下部が (−3.0,−5.5)/(+2.2,−5.8) px 動き、体の衣装は (0,0)。BodyAngleX +10 は顔 +28.3、左右上部 +29.6/+29.7、左右下部 +37.0/+37.0、衣装 +42.1 px。上部は頭に近づいたが完全一致せず、下部も体追従そのものではない。

固定7姿勢（rest、AngleX±20、AngleZ±10、BodyAngleX±10）では顔・目・口・前髪の描画後頂点は v10h と一致した。合成画素は三つ編みとの重なりで変わりうる。AngleZ +10 の静止画では結び目の大きな破断は見えないが、肩下の移動と補間による折れの全軌道検証・実 GPU 確認は未完了。
