# full-v10i の再現メモ

評価と制約は [REPORT.md](REPORT.md)。`repair.py` は v10h の保存済み `.psd2live` を開き、後ろ髪上部の追従キーを追加する。`repair.sh` は固定 digest の JDK/Python とログ無効の MCP を使い、指定 Docker volume `boxp441-i` の `/work` に出力する。このスクリプトは volume の準備を行わない。再現時は `/work/psd2live` に v10g の anchor patch 適用済み checkout（commit `6fe868a20c7bf12586fa8ce0a05982f099faa865`）、`/work/gradle-cache` に従来の cache、`/work/baseline.psd2live` に v10h の保存済みプロジェクト、`/work/rest-geom.json` に基準 rest の全メッシュ情報、`/work/repair.py` に本ディレクトリのスクリプトを置いてから実行する。基準 p2lrt 自体は v10h の既存成果物を使用する。MCP コンテナは `--log-driver none`。token はスクリプト内で生成し、表示しない。

`capture.cjs` / `capture-i.cjs` は `/dist` に Web build、`/deps/node_modules/playwright` に Playwright 1.56.1、`/work/params.json` と候補 `/work/candidate.p2lrt` がある環境で、基準・候補の二色画像、全メッシュ情報とアトラスを取得する。`analyze.py` / `analyze-i.py` は `/work/pydeps` の NumPy 2.5.4、SciPy 1.18.1、Pillow 13.0.0 を使い `/work` と `/work/i` を分析する。`compare.py` は今回の作業ディレクトリの幾何・成分・`probe-workspace_inspect.json` / `probe-workspace_overview.json` から親・追従・変位と比較表を加える。`layers.cjs`、`diagrams.py` は層・ワイヤ診断、`videos.cjs`、`encode.sh`、`sheets.py` は録画とシート、`rest.cjs` は静止比較、`smoke.cjs` は組み込み画面と比較リンクの読込確認。スクリプト内の `/work` と `/dist` は Docker volume / コンテナ上の作業パスであり、ホストの bind mount を前提としない。動画の MP4 化にはコンテナの ffmpeg が必要。
