# v22（上唇の画素を流用した試作）

v17 の位置合わせ・肌色補正済み半開き画像から上端の暗い画素と口角を抽出し、それ以外の口内を周辺色で補完した閉口層に置き換える。補完は OpenCV Telea、閉口・半開きの不透明度は v17 と同じ。画像生成は行わない。既存の半開き画像の暗い歯や口内が上端と接しているため、抽出の見た目は静止比較で確認する必要がある。

`rebuild.sh VAULT WORK_DIR` が v17 と v22 の静止描画とモデルを出力する。`uv run --with pillow python apps/kohako-studio/rig/kohako-v22/make_compare.py WORK_DIR OUTPUT_DIR` で比較 JPEG を作成する。原画は全ポーズ共通の静止画像であり、描画は物理シミュレーションを含まない。

拡大比較の結果は不採用。閉口で線が途切れ、口角の赤い断片が残る。口 0.2〜0.3 でも上下の線が分離し、X ±30 の閉口も不自然だった。比較画像の v22 列は試作そのものを示し、配備モデルは v17 のまま。
