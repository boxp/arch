# BOXP-470 TD-07: kohako-full-v11p

v11o の後ろ髪で、体・腕・パネルに隠れていて原画に存在しなかった部分だけを、Owner 承認の範囲（Codex 組込み image_gen、失敗込み最大 2 回）で補完した版。見えている後ろ髪は原画の画素のまま。顔・目・口・三つ編み・髪飾り・衣装の層と `build.py` の rig 指定は v11o のままで、変更は `back_hair` と `arm_right` / `arm_left` の層だけ（v11o の layout に対する `cmp` で他の層は一致）。

## 生成

- 1 回使用（失敗 0、2 回目は使っていない）。Codex 組込み image_gen（ChatGPT ログイン）。Gemini・従量 API・追加購入はなし。
- 出力は Project の `live2d/gen/codex-back-hair-fill-470-1.png`（sha256 `837a05fd…`）。入力 sha、prompt、生成情報は同名 `.json`、経緯は `live2d/gen/provenance.md`。
- 参照は緑地の位置ガイド（見えている髪と補完範囲）、公式シート、KV v2 を実添付。

## 手順

`prepare_v11p.py` を v11o の layout のコピーに適用（`LAYOUT`、`ART`=kohako-full-art-v0 の JPEG、`GEN`=上の出力、`MASK`=`target-mask-layout.png`、`PENT`=腕インナーのマスク）してから `build.sh` に渡す。出力 p2lrt の SHA-256: `f09257458ce183e97c81d7c5bdec80a5e7642179a617b7559549d267c8c56918`。

## 変更内容

1. 腕の黒いインナーを `back_hair` から腕の層へ移す（左右 4,852 / 4,895 px、新しい絵は描かない）。
2. 生成素材を見えている髪で位置合わせ（四隅のずれ 0.67 px）し、補完範囲の中だけ置き換える。境界 5 px をなじませる。
3. 生成素材が届かない肩の裏（y<560）は v11o の髪のまま（6,493 px）。消すと肩上の髪に穴が出るため。
4. 補完範囲の外で見えている髪は原画へ戻す。背景を髪で埋めていた箇所は背景へ戻し、輪郭は白地から分離して点線が出ないようにする。
5. 40 px 未満の孤立した小片を除去（22 片）。

## 確認（実 Chromium / SwiftShader、v11o と同一軌道: 体 X ±5、体 Z ±3、頭 X ±15、頭 Z ±6、固定刻みの物理、160 フレーム）

素材の機械判定はいずれも基準内: 暖色 0 px（基準 20 以下）、マゼンタ残り 0 px、低テクスチャ率 0.208（基準 0.35 以下、v11o は 0.71）。

- 担当の目視（`compare/kohako-full-v11p-hair.jpg`、`-pair.mp4`、`-body.mp4`、`-arm.mp4`）: 隠れていた部分のぼかしの塊・腕の輪郭のにじみ・点線は解消し、体を回したときに毛流れが見えている髪からつながる。
- `閉じた背景露出`は増えたが、増加分は原画の毛束の隙間を戻した分。静止時の原画の隙間を半径 17 px 以上広げて除くと v11o 以下になる（半径 25 / 35 px でも同じ傾向）。ただしこの除外は体回転で隙間が動く量（体 X で約 12 px）を近似したもので、半径の選択は事後判断。
- 実 Hermes 会話（`verify/video/run.sh kohako-full-v11p studio pc`）の発話状態: 全開 519/600 フレーム、半眼帯の連続最大 7、閉眼はまばたきの通過のみ。v11o（全開 518/582、連続最大 7）と同水準。Brow +0.29、MouthForm +0.69 で表情も維持。
- 顔領域の描画差は同一モデルを描き直した差（平均 1.9〜4.4）以下で、顔・口の層は v11o とバイト一致。
