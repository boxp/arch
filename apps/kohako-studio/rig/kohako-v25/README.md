# kohako-v25

v24 の髪飾り修正と目のキーを維持し、v23 の閉口素材を `face` / `detail` タグで戻します。生成器の `MOUTH_CLOSE` 切替対象にせず `DeformFaceNinePose` に追従します。開口メッシュの不透明度は 0→0、0.08→1、1→1、顔詳細の閉口線は 0→1、0.08→0、1→0 です。

`rebuild.sh` が v23 の layout から生成、キー設定、保存、描画、export します。`create_parts.py` は髪飾りを補正し、`eyes.py` は v24 と同じキー、`mouth.py` は口のキーを設定、`capture.py` は検証画像を描画します。`compare.py` は同条件の描画から比較 JPEG を作ります。

実測: 口 0 は笑み線のみ、0.08/0.1/0.25/0.5/1 は単一の開口形です。0.04 は遷移中で両線が薄く重なります。AngleX ±30 / AngleY ±20 で閉口線が顔に追従し、X+30 で黒い花形は見られません。目 0/0.15/0.5 の描画は v24 と画素単位で一致しました。p2lrt export の losses は空です。本人確認前の試作です。
