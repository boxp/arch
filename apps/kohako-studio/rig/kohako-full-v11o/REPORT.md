# BOXP-470: kohako-full-v11o

v11n に対する Owner の所見（太ももの外側のずれ、スカートの両端の欠け、まばたきの瞳）を、生成なしで層とレイアウトから直した版。顔・口・表情のパーツと `build.py` は v11n のままで、変更は `prepare_v11o.py` の層の加工だけ。画像生成、Gemini、外部画像 API は使っていない。

## 手順

`rig/kohako-full-v11n` の出力 layout のコピーに `prepare_v11o.py` を適用し（`LAYOUT`、`ART`=kohako-full-art-v0 の JPEG）、`build.sh` に渡す。出力 p2lrt の SHA-256: `bfcd33cf3f09b2bd79eb27f8f3b104674646f0b488789ad6538a1503c87cece0`。

## 前回判定の更新

v11n で「解消」とした内側の帯と段差の修正は別の症状で、Owner の所見は解消していなかった。今回、原画と同じ尺度で並べ、層の矩形端と原画シルエットの棚卸しを追加して再現した。

## 原因（原画との同尺度比較、層単独、`layout.json` の rect）

| 症状 | 原因 |
|---|---|
| スカートの両端の欠け | `panel_right` / `panel_left` の rect が原画の内側（x=291 / x=854）で終わり、裾の丸い角と外周線が縦の直線で切れていた。静止時から欠けている |
| 太ももの外側のずれ | `leg_right` / `leg_left` の rect が x=425 / x=719 で終わり、y<1262 の太もも外側の帯がパネル層に残ってパネルと一緒に動いていた。y≈1262 より下は脚と動くので段差が出る |
| まばたきの瞳 | 半開きの目（`eye_mid_*`）の虹彩は、暗い上部とハイライトが無く淡い下半分だけだった。開眼や全身化前の v45 の半開きと瞳の濃さが合わない |

## 修正

1. パネルの rect を x=262 / 882 へ広げ、裾の丸い角と外周線を原画から戻す（行ごとに原画を白地まで走査し、外周線より内側の明るい帯は不透明にする）。
2. 脚の rect を x=380 / 763 へ広げ、太もも外側の帯をパネルから脚へ移す。パネルの内側の外周線はパネルに残す。パネルの下には脚のカバレッジを延ばし、裾の先の空白部分は太ももの輪郭より外へ出さない。
3. 半開きの目は、受入済みの開眼層（白目・虹彩）を上まぶたで 30% 隠して下まぶたへ合わせて作り直し、ハイライトは潰さず瞼の下に置き直す。まぶたの線・まつ毛・目の alpha は変えない。開眼 0.975 の切替位置は v11j/k の経緯（開眼層の変形で虹彩が潰れる）があるため維持。

## 確認（実 Chromium / SwiftShader）

- `compare/kohako-full-v11o-skirt.jpg` / `-thigh.jpg`: 原画・v11n・v11o の同尺度比較。
- 静止時の原画シルエットに対する裾・太もも帯の未描画画素: 715 → 22。裾の 2 つの欠損（14×75 px、12×68 px）は消失。
- `compare/kohako-full-v11o-pair.mp4` / `-body.mp4`: 同一軌道（体 X ±5、体 Z ±3、頭 X ±15、頭 Z ±6、固定刻みの物理）8 秒の左 v11n / 右 v11o。太もも外側のシルエットの行間ジャンプ（y 1256〜1300、両脚 × 160 フレーム）: p95 12 → 1 px。
- `compare/kohako-full-v11o-blink.jpg` / `-blink-seq.jpg`: 開度スイープと同じ開閉軌道（24 フレーム）で v45 / v11n / v11o を比較。半開きで虹彩の濃い上部とハイライトが残り、開眼と色がつながる。
- 閉じた背景露出は v11n と同じ（平均 1601 px、最大 1837、20 px 以上の隙間 16.1）で退行なし。
