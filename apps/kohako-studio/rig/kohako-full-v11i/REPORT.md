## 実験と確定したこと

第一案は `hair_front` と画面右の開眼まつ毛の重複領域を切り出して顔の直上に配置し、元の前髪と同じ physics deformer に bind した。bind 成功を確認したが、実 Chromium の静止・AngleX ±20・AngleZ −10 で目尻に背景色の縦の欠けが見え、採用しなかった。親が同じでも、別メッシュの変形と境界が一致するとは限らない。`corner-split.jpg` が失敗例。p2lrt SHA `a75fc19ad3a61a6de0c7d9972e3bcbb7a07b424ba48048850828290e1fb3bd1c`。

下まぶたは左右 lash の画像 y=67..75 を別メッシュにし、同じ目の親に bind して開度 0.89 以下で非表示、0.90 以上で表示する試作を行った。これは上記の第一案に追加したため、下まぶたの比較は第一案同士で行った。0.85〜0.65 の暗い四角い下線は消えるが、虹彩下端が白目から突出した印象が強く、1.0 の下線にも差が出た。目元 crop で RGB 差 >3 の画素は開度 1.00/0.95/0.90/0.85/0.75/0.65 = 739/1598/2113/2403/2742/2972（JPEG と再描画差を含む）。見た目の退行があるため採用せず、`lash-trial.jpg` に示す。上まつ毛は維持した。0.60 の灰色重なりと 0.15→0.10 の段差は未解決。v44/v45 の REPORT.md は存在しないため README とスクリプトを参照し、幅 0.004、中心 0.135/0.60 の切替が v11g に既に適用されていることを確認。0.60 は交差区間の中点なので灰色は残る。閉眼と半眼の素材形状差による段差も短区間化だけでは消えない。

体の診断は Chromium / SwiftShader、DPR 2、動作停止、マゼンタ背景、BodyAngleX −10/0/+10。`body-layers.jpg` は全層・胴単独・腕単独・髪単独・各層除外。手の周囲の小片は髪単独に現れ、髪除外で消える。後ろ髪入力の alpha > 128 は 15 連結成分を持ち、`backhair-source.jpg` に腕付近の輪郭や分離小片が見える。少なくとも小片の一部は後ろ髪層由来。腕・長髪の裂け全体に対する幾何の隙間、z 順、切断辺の寄与は未確定であり、これらを原因と断定できない。v37 `patch_body.py` は肩下の後ろ髪を胴回転へ追従させる手法だが、入力にある腕状の残片自体は消さず、全身での影響も未検証のため適用しなかった。腕・長髪の修正は未完。

実 Web で v11g を各状態 10 秒、100 ms 間隔で測定した BodyAngleX の観測最小〜最大は待機 −4.51〜4.16、考え中 −4.21〜5.15、発話状態 −4.15〜3.87。発話状態の pose を選択した測定で、音声再生や全動作の絶対範囲ではない。±10 の診断は観測した通常範囲より大きい。

## 採用した比較試作と描画

第二案として、画面右の開眼まつ毛と前髪の重複領域を `lash_corner_overlay` に複製し、前髪より上の描画順に置いた。元の前髪・元のまつ毛はそのまま、複製層は元のまつ毛と同じ目の親へ bind し、EyeLOpen の不透明度を既存 lash と同じ 0/.598/.602/1 のキーにする。v11g と同じ入力を `prepare.py` で準備した後、`prepare_overlay.py` を一度適用して `build.sh` に渡す。既存の入力と削除対象の重なり検査、一意なコンテナと volume、MCP log-driver none、anchor.patch の逆適用確認、MCP/export 双方の髪環境変数を維持した。MCP import / rig / export 成功。p2lrt SHA-256: `b01fd56501851d7439f584f0c97005b45117aed1f4d2d049f6527340966f2975`。

`static.jpg` と `grid.jpg` は原画 v0 / v11g / v11i、同じ虹彩基準で顔を正規化しており、静止画像には上半身も併記した。虹彩重心の Chromium 描画位置も v11g/v11i で同一（左 372.265, 244.778／右 470.604, 247.459 device px）。`cheeks.jpg` は AngleX ±20・AngleZ ±10。画面右のまつ毛の上に一部描線が足されるが、見た目の改善は小さく、前髪の被りは残る。実際に RGB 差が 3 超の画素は正面 60、X− 45、X＋ 69、Z− 61、Z＋ 61、いずれも目尻付近。したがって目尻が完全に修復されたとは言えない。`closed.jpg` は正面と AngleX ±20 の閉眼比較で、v11g/v11i に RGB 差 >3 は各 0 画素、前髪内の新たな穴も見えなかった。これは指定姿勢での比較であり全動作を保証しない。
