# BOXP-470 TD-02: kohako-full-v11q

v11p の後ろ髪は生成素材の時点では繋がっていたが、合成で切れていた（独立レビュー BOXP-473）。v11q は v11p と同じ生成素材（`codex-back-hair-fill-470-1.png`、sha256 `837a05fd…`）で合成だけをやり直した比較候補。**新規の画像生成はしていない。** 既定モデルは v11p のまま（`?model=kohako-full-v11q` で表示）。

## 手順

`prepare_v11q.py` を v11o の layout のコピーに適用（`LAYOUT`、`ART`、`GEN`、`MASK`=`target-mask-layout.png`、`PENT`）してから `build.sh` に渡す。出力 p2lrt の SHA-256: `4e6625a1a8a3bab6f66b22c76595f75a3c7e7d51d5cf33b4dd4074933aeb82f9`。

## 変更内容（v11p との違い）

1. 原画の背景だった画素を生成素材へ打ち抜かない（毛先のスリットの原因）。
2. 多角形 mask で生成素材を切らない（体側の角ばった欠けの原因）。
3. 原画の見える髪を生成素材の上に重ね、隠れ部分との境界は 12 px、腕・パネルとの境界は 6 px でなじませる。原画の外周と原画の隙間の縁はぼかさない。
4. 背景に近い原画の縁は白地から分離し、白い点線を焼き込まない。
5. 継ぎ目の細い線の残りと孤立片、腕の輪郭の色の画素は重ねない。生成素材の 120 px 未満のピンホールは周囲の色で閉じる。

変更した層は `back_hair` と、v11p と同じ腕インナー移動の `arm_right` / `arm_left` のみ（v11o layout との `cmp`。腕の 2 層は v11p と一致）。

## 確認（実 Chromium / SwiftShader。v11o・v11p と同一軌道: 体 X ±5、体 Z ±3、頭 X ±15、頭 Z ±6、固定刻みの物理、160 フレーム）

| 項目 | v11o | v11p | v11q | レビューの基準 |
|---|---:|---:|---:|---|
| 削られた生成画素 | - | 4,589 px（レビュー値） | 0 px | 0 近傍: 達成 |
| 髪に囲まれた穴 | 7 | 36 | 3 | v11o 以下: 達成（本版の定義） |
| 隠れ領域の透明成分 / 小穴 | 10 / 6 | 46 / 36 | 21 / 10 | v11o 以下: 未達（下記） |
| 閉じた背景露出 平均 / 最大（除外半径なし） | 1,600 / 1,845 px | 2,363 / 2,683 px | 2,083 / 2,438 px | v11o 以下: **未達** |
| 白っぽい不透明の縁の画素 | 880 | 1,510 | 47 | 参考 |
| 多角形 mask 境界に乗る透明境界の画素 | 387 | 1,211 | 621 | 生成素材単体 567 と同水準 |
| 15 px 以上の直線の透明境界（4 方向） | 36 | 34 | 31 | 0: 未達（生成素材単体でも 33） |
| 太もも段差 p95 | 1 px | 1 px | 1 px | 維持 |

- 「透明成分 / 小穴」は領域で切り取った外周の背景も数える定義（半径 20 px、4 連結、alpha 128 以下）。レビュー文書の数値（52/42 など）とは別の定義で、レビューの数値は再現できていない。v11q の残りは毛先の外側の背景が中心で、髪の内部の穴ではない（`髪に囲まれた穴` の行を参照）。
- `閉じた背景露出` は v11o の基準に届かない。v11o は隠れ部分を下地の塊で埋めていたため数字が小さい。
- 比較物: `compare/kohako-full-v11q-hair.jpg`（原画 / v11o / v11p / v11q の 4 列 × 静止・体 X+5・体 X−5 の 3 行、腕帯の左右）、`-pair.mp4` / `-body.mp4` / `-arm.mp4`（左から v11o / v11p / v11q の同一軌道）。

## 未確認・残件

- 静止時に前腕とパネルの間の背景が生成の髪で埋まる（`fill_over_art_background_px` 2,316 px）。原画のシルエットからの変更で、Owner の判断が必要。

- 腕の外側で原画の毛束が生成の毛束に乗り換える箇所は、毛量と毛先の形が原画と異なる。
