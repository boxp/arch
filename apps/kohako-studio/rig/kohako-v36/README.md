# kohako-v36: 後ろ髪が顔と無関係にずれて動く点を修正（BOXP-441 TD-26、固定 URL 最新試作）

**今回の画像生成 0 回**（髪枠は 2026-11-07 04:02Z の肩/衣装下地 1/4 のみ使用済みのまま）。公式 Cubism Core 不使用。素材・レイヤーは v35 と同じ。

## 原因の切り分け（配備 v35、`verify/video/motion.mjs`）
顔向き・待機モーション・髪の物理を 1 つずつ分け、顔／前髪／衣装と後ろ髪（縦 6 帯）の変形後頂点の平均変位を比べた（canvas px）。
- 顔向き AngleX +20（物理なし）: 顔 +8.0・前髪 +9.3 に対し後ろ髪の根元 0.0、下ほど −1.4（psd2live 既定の逆向き視差 backHairTurn 1.8%）。**根元が顔に付いてこない。**
- 首の傾き AngleZ +10（物理なし）: 頭頂側は頭と一緒に回る（+41）が、肩より下の帯は −10.6 / −17.1 / −19.4（衣装は 0）。
  psd2live の HairRoll（顎より下を頭の支点まわりに逆回転、hairRollHold 80%）が、v29 以降の胸までの長い後ろ髪では打ち消し切れず、
  **体は動かないのに長い髪が顔と逆へ動く**。hairRollHold を上限 100 にしても −12.7 までしか戻らない（3×4 の粗いワープと支点のずれ）。
- 髪の物理 PhysicsHairBack（r15 / 出力 scale 2.061）: 待機中の首振り（顔 −7.6→+7.9px、0.5 秒）で毛先が −24→+7px と顔の約 2 倍・約 0.2 秒遅れの逆位相に振れる。
  backHairSway 10% が長くなった後ろ髪全体に掛かり、振れ幅が大きい。
- 待機モーションの取り違え（別の原因）: v25 以降のビルドはモーション ID が m14〜m17 なのに画面の対応表が m13〜m16 のままで、
  **待機中に Shake（首振り）が周期的に再生**され、失敗時の Shake は無かった。対応表を直した（v25/v27/v29/v30/v35/v36）。
- 風・自発振動なし（全 parameter 既定で 10 秒静止させると収束）。

## 修正
1. `backhair-anchor.patch`（`patch_psd2live.py` が隔離コピーの psd2live 6fe868a に当てる。`P2L_BACKHAIR_ANCHOR=1` のときだけ有効）:
   後ろ髪の追従ワープ（`hairFollowWarp`、後ろ髪のみ）を 3×8 にし、各点を顎（y≈345）〜肩（y 425）の smoothstep で
   「頭側: 頭の向き・うなずきに追従（FX 15px / FY −6px、AngleX ±45・AngleY ±30 のとき）」と
   「体側: 首の傾きを頭の支点まわりに完全に打ち消す（G 1）」に分けた。
2. hair/legacy モディファイアの tuning: backHairSway 10→7、backHairTurn 1.8→0。物理 PhysicsHairBack の出力 scale 2.061→1.2（毛先の遅れは残す）。

## 結果（v35 → v36、同じページ・同じ動き。物理なしの数値は 6 帯の平均）
- AngleX +20: 後ろ髪の根元 0.0→+9.8（前髪 +8.9）、肩より下 −1.4→+0.4。
- AngleZ +10: 肩より下 −10.6/−17.1/−19.4 → −2.6/−0.9/−1.2（衣装 0）。毛先は上下に −8.8px 残る（待機の傾き ±4° で ±3px 程度）。
- AngleY +20: 根元 −2.1→−6.0（前髪 −6.2）。
- 自然動作の「後ろ髪 − 基準（上 2 帯=前髪、下 2 帯=衣装）」の標準偏差: 頭頂 5.1→3.2、毛先 5.1→2.2px。
- 録画（`compare/kohako-v36-*`）: v35 で待機の首振り・考え中に肩の外側の長い房が肩当てから離れて外へ振れていたのが、v36 では肩に沿ったまま。
  大きな首振り（±25°）でも根元から肩への移行帯に裂け・段差は見当たらない。
