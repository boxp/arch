# BOXP-470 TD-09: kohako-full-v11r

v11q を修正基準に、Owner が指摘した「手とスカートの間の謎の線」を生成なしで是正した版。Owner の A 受入（腕と衣装の間が髪で埋まる見え方を含む）で既定モデルへ昇格した（`?model=kohako-full-v11p` などで以前の版を表示できる）。`back_hair` は v11q と byte 一致で、改善した毛束はそのまま残している。**新規の画像生成はしていない。**

## 線の出所（v11q の層単独・除外描画・色分け帰属）

線は後ろ髪ではない（後ろ髪なしの描画でも残る）。次の画素が腕とパネルの間に焼き込まれ、髪と別に動いていた。

| 層 | 残っていたもの |
|---|---|
| `panel_right` / `panel_left` | 下端が水平に切れた腕のコピー（水平の切断線）、横一直線の細い筋、青灰色の楔、原画の白地の縁（点線に見える） |
| `arm_right` / `arm_left` | 前腕の内側の髪の塊とパネル上端の金色の小片 |
| `body` | カフ横の黄土色の下塗り（腕の断片に隠れていたため、断片の除去で露出した。原画にない） |

## 手順

`prepare_v11r.py` を v11q の layout のコピーに適用（`LAYOUT`、`ART`、`METRICS`）してから `build.sh` に渡す。出力 p2lrt の SHA-256: `4ddd0fe22fa1eb3b8d50fe95ff54d6d7d3cba885f89f5762f9763cbdb975da6d`。

- 原画の色の連結成分（腕・パネルの本体）とその輪郭だけを対象領域に残す。領域は腕とパネルの間に限定。
- 腕とパネルの輪郭と、輪郭が欠けていた箇所は原画の画素で置き換えて、画と一致させる。
- `body` は該当の矩形内の下塗りのみ除去。

変更した層は `arm_right`、`arm_left`、`panel_right`、`panel_left`、`body` の 5 層で、対象領域の外は byte 一致（層ごとの領域外の差分 0）。

## 確認（実 Chromium / SwiftShader。v11q と同一軌道: 体 X ±5、体 Z ±3、頭 X ±15、頭 Z ±6、固定刻みの物理、160 フレーム）

| 項目 | 結果 |
|---|---|
| 層から除いた画素（alpha 64 超→以下） | panel 右 6,544 / 左 8,742、arm 右 2,412 / 左 2,574、body 5,023 px |
| 静止・体 X ±5 の目視（`compare/kohako-full-v11r-hair.jpg`、原画 / v11q / v11r） | 点線、水平の切断線、断片の消失 |
| 同一軌道 160 フレームの目視（`-arm.mp4` / `-pair.mp4` / `-body.mp4`、左 v11q 右 v11r） | 上記の線と断片が動作中も出ない |
| 全身（対象領域の外）の差分、静止 | 平均 0.049 / 255、差 20 超の画素 0.07% |
| 体 X ±10、体 Z +5 の全身目視 | 線の再発なし |

動画の左右は同じ軌道・固定刻みの物理で揃えている。

## 未確認・残件

- 実機 GPU の見え方は未検証（SwiftShader のソフト描画のみ）。本人の美術受入は Owner の A で完了。
- 体 X ±10 では前腕の内側にごく小さな黒い出っ張りが残る（通常動作の体 X は ±4.6 程度）。
- 細い線の専用の定量指標は取れていない（薄い細線を数える粗い指標は 1,016→859 px だが、パネルのハイライトや毛束を含むので根拠には使わない）。判定は層別の出所特定と同一軌道の目視による。
- 実 Hermes 会話（配備後）: 全開 519/600 フレーム、半眼帯の連続最大 8（v11q と同じ）。顔・口の層は v11q と一致。
