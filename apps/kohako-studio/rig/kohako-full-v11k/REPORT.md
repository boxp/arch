# BOXP-441 TD-43〜46: kohako-full-v11k

本人受入済みの顔配置（v11g / v11j）を保持した、本人指摘 4 点の修正版。全身の美術受入前の試作。画像生成、Gemini、外部画像 API、Core 取得は行っていない（頭部キット枠は 3/5 のまま）。

## 手順

`rig/kohako-full-v11j` の layout コピーに `prepare_v11k.py` を適用（`LAYOUT`、`ART`=kohako-full-art-v0 の JPEG）し、`build.sh` に渡す。出力 p2lrt の SHA-256: `dede7b20ed7fd56f20ed9f2b058d022a93e1d6d5f071f489ebed982378088de7`。`build.py` は v11j との差分として目の開眼切替を 0.898〜0.902 から 0.975〜0.979 に変更している。

## 原因と修正

- **キャラ左の髪（TD-43）**: 頬横の房は胸像由来の移植層で、受入原画より 15〜20 px 狭く、v11j の前髪調整で切り口が階段状になっていた。原画の画素で房（x≧649、y≦360）を作り直し、前髪層の該当部をなじませた。頭頂の外周と長髪の欠けは原画から後ろ髪層へ戻した（シルエットの欠け 36,186 px に対し、髪 6,420 px を復元）。
- **まばたき（TD-44）**: 開度 0.90 で全開から半眼へ切り替わる瞬間に重なって二重像になり、0.92〜0.95 は開眼層の変形で虹彩が潰れていた。切替をほぼ全開の 0.975〜0.979 へ移した。素材の開眼・半眼・閉眼は変えていない（段階的な切替自体は残る）。
- **白い切れ目（TD-45）**: 背景の露出は、(1) 切断縁の白にじみ、(2) 層の小さな穴、(3) 動きで開く層の隙間に分かれた。(1) 白にじみの除去と縁の色の除染、(2) 穴の補修、(3) 下の層を上の層の下へ 26 px 延ばす処理と、頭部全体の下地で対処した。延ばした部分は静止時には上の層に隠れる。可動域は変えていない。
- **口（TD-46）**: 開口時に中央の淡い塊が歯のように見えていた。口内を暗くし、舌を低く柔らかい色にした。閉口線は半開きの口の上唇の線に揃えて 1 本にした。

## 確認（実 Chromium、配備版ページに候補 p2lrt を差替え）

`compare/kohako-full-v11k-*.jpg|mp4` に、原画 / v11j / v11k の比較と、自然動作の同時刻動画を置いた。首振り（AngleX ±20）と体の回転（BodyAngleX ±5）で、v11j の大きな隙間は目立たなくなった。
