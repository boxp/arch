# notice772.mjs（BOXP-772）

`notice772.mjs`（BOXP-772）は BFF を完全にモックし、PC と Pixel 7 相当で通知からのジャンプが一度だけ行われることを検証します。`?notification=` 付きで開いたときに対象通知を 1 度だけ開き `notification` だけを履歴を増やさず URL から外すこと、`visibilitychange`（同じタブの再利用）と再読み込みで再表示しないこと、受信箱から明示的に開けて返信先が開いている通知のままであること、開いたままの画面への Service Worker の `open-notification` で URL を変えずに開くこと、一覧取得が失敗したときや、一覧は取れたが開く途中の案内済み送信が通信失敗したとき、案内済み・既読の送信が JSON 付きの HTTP 500 を返したときは受信箱を開かず消費せず URL も残し次の取得で 1 度だけ開くこと、外部通信 0 件を確かめます。ビルドを `SITE`（既定 `/site`）の `kohako/` に置き、Playwright 1.56.1 で `node notice772.mjs /out` を実行します（`PORT` 既定 8812）。結果は `result.json` に保存し、失敗時は終了コード 1 です。
