# reauth523.mjs（BOXP-523）

BFF をモックして PC（1280×800）と mobile（412×915）で実行する。a〜d は認証切れ時の手動再読み込み、通常の再接続、再認証失敗時の自動再読み込み防止、控えの照会を確認する。e〜h は控えと同文の草稿・送信待ちの復元、満杯時の退避、控えを入力欄に写さないことを確認する。i〜k は初期化中の手入力を失わないことを確認する。l・m は照会失敗後の同文入力を新しい発言として一件残し、控えの受付番号で重複 POST しないことを確認する。n は再読み込み後も認証できない画面で別の文を入力して再度押しても、前回退避した草稿・送信待ちを上書きせず両方戻すことを確認する。

ビルドを `SITE` の `kohako/` に置き、Playwright 1.56.1 で `node reauth523.mjs <out>` を実行する。結果は `result.json` に保存し、失敗時は終了コード 1。

2026-11-15 の検証では新版は PC・mobile とも a〜m が全件成功。その後 n を追加し、新版は a〜n 全件成功、旧版 4a30ce18ab は n のみ両画面で失敗（前回退避の草稿が新しい入力で上書き）。旧版 c48aef5886 は両画面で a〜f・h〜k が成功し、g は旧仕様の確認ダイアログで再読み込み待ちがタイムアウト、l・m は手入力の同文が送信待ちに残らず失敗した。
