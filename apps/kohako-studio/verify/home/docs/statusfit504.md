# statusfit504.mjs（BOXP-504 TD-02）

`statusfit504.mjs` は `STATUS_JSON`（BFF `/kohako/api/v1/status` 応答の実データ写し）と BFF モックで、利用枠ウィジェットの大きさが変わっても周りを覆わないかを実ブラウザで確かめます（token 不要）。

- 情報量: `few`（Antigravity 群なし＝BOXP-637 以前と同じ）、`live`（写しそのまま）、`max`（全帯 88.8%・進行中 agent 5 種）。値の書き換えは検証用の写しの中だけです。
- 画面: PC 1280×800 / 1024×640、スマホ横 844×390 / 667×375 / 932×430、スマホ縦 390×844（BOXP-544 で非表示のまま）× 待機・会話・結果表示。文字 125%（`html{font-size:125%}`）と長い吹き出しも含め 54 場面。
- 判定: ウィジェットが舞台内にあり、入力・送信・停止・吹き出し・カード・時計・日付・挨拶と重ならない、スマホ横の会話/結果でコハコの中央と重ならない、帯・ゲージ・チップの文字が切れず 9px 以上、数値のある帯がすべて出る、進行中合計が応答と一致、詳細が舞台内に収まり最後までスクロールでき Esc で閉じる。
- 使い方: ローカル build を `$SITE/kohako/`（既定 `/site/kohako/`）に置き `STATUS_JSON=/work/status.json node statusfit504.mjs out/<name>`。結果は `out/<name>/result.json` とスクリーンショット。
