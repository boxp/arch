# retention647.mjs（BOXP-647）

BFF をモックし、PC とスマホ縦・横画面の短文・長文を並行して実時間 67 秒待つ。relax 後の表示、長文スクロール位置と末尾、履歴、入力、次の返答への置換、設定切替と読み上げありの返答に保持状態が残らないことを検証する。音声 API はモックのため再生品質は対象外。`SITE` は `kohako/` に web build を置いた親ディレクトリ、引数は結果とスクリーンショットの保存先。Playwright 1.56.1 が必要。外部通信と検査失敗は終了コード 1。

## P1 回帰: retention647-touch.mjs

ビルドしたWebを `BASE_URL`（既定 `http://127.0.0.1:8847`）の `/kohako/` で配信し、Playwrightを使える環境で `node retention647-touch.mjs <証跡保存先>` を実行する。必要なら `CHROMIUM` にブラウザ実行ファイルを指定する。PC/スマホ縦横で連続ふれあい後の本文・保持復元、実時間67秒後の表示、一時表示中の新返答への切替を確認する。BFFはモックし、外部通信は遮断・失敗扱いにする。連続操作を4.5秒の一時表示内に行うため、15秒の送信制限判定には `Date.now` を進める。
