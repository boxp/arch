# choices646.mjs（BOXP-646）

BFF をモックし PC と Pixel 7 相当で、選択肢の表示と返信を会話・通知吹き出し・受信箱で同じ規則にそろえたことを検証する。1 行併記の選択肢（BOXP-644 の書き方）が説明付きボタンになり自由文欄も並ぶこと、選択は記号で元 event へ一度だけ送ること、手順の番号付き箇条書きはボタンにしないこと、会話の返答の選択肢ボタンが「1：説明」を通常の発言として一度だけ送り下書きと下書きの添付を消さず（添付を選択に混ぜず）承認 API を呼ばないこと、自由文で答えるか次の発言で古いボタンが閉じて別の依頼へ結び付かないことを確かめる。Playwright 1.56.1 で `SITE`（既定 `/site`）の `kohako/` にビルドを用意し、`node choices646.mjs /out` を実行する（`PORT` 既定 8846）。結果は `result.json` と各画面のスクリーンショット、失敗時は終了コード 1。外部通信も失敗扱い。
