# location648-compact.mjs

`location648-compact.mjs` は BOXP-648 TD-02（入力欄まわりの位置表示が大きすぎる件）を、BFF モックと架空の位置（東京駅付近の公開地点）で検証します。本人の実位置は使いません。PC・狭い PC・スマホ縦・スマホ横の各画面で、共有 OFF と比べて入力バーの高さが増えないこと、入力欄の幅を 8 割以上保つこと、位置表示がボタン列に収まりはみ出さないこと、共有中（`📍HH:MM`、縦画面では 📍 の下に時刻・状態を小さく表示）・取り直し失敗（`⚠`）・未許可が短い表示と注意色で分かること、押すと理由の全文が開閉すること、OFF で消えること、ブラウザ保存に座標が残らないことを確かめます。ビルドを `SITE`（既定 `/site`）の `kohako/` に配置し、必要に応じて `PORT` と出力ディレクトリ引数を指定して実行します。
