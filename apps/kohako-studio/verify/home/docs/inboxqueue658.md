# inboxqueue658.mjs（BOXP-658）

`inboxqueue658.mjs`（BOXP-658）は token 不要の完全な BFF モックを使い、PC と Pixel 7 相当で、応答待ち中に受信箱の詳細（選択肢・自由文）と吹き出しのお知らせから返信すると BFF へ送らず送信待ちへ積まれること、通常の発言と同じ FIFO で現在の依頼が正常に終わってから 1 件ずつ通知の返信 API（登録時の replyId）へ送られること、待機中の「A」「OK」が承認や通常発言に使われないこと、連打・重複・取消（自由文は下書きへ戻る）、送信直前の通知状態確認（別端末の先行返信・選択肢変更・通知消失で送らずに保留）、返信 API の応答が失われても受理済みなら送信済みとして扱うこと、成否不明の保留を取り消す前にサーバー側の受理を確かめ受理済みなら「取り消せませんでした」と表示すること、一度送った返信は未返信・受理途中に見えても取り消さず（一括取消でも残す）、サーバーが実行しないと確定した場合（別の返信が先行・通知消失）だけ取り消せ、同じ replyId の送信失敗記録（submit_failed）は「取り消した」と表示せず送信待ちから外して受信箱の記録へ委ねること、再認証の退避が前後に空白のある選択肢も復元すること、取消のための受理確認中は「再開」・自動送信ができないこと、成否不明（502）・BFF busy（429）・認証切れ（401）で保留し再開でも同じ replyId だけを再送すること、未送信本文を保存しないこと、再読み込みの確認、外部通信 0 件を検証します。

ビルドを `SITE`（既定 `/site`）の `kohako/` に置き、Playwright 1.56.1 で `node inboxqueue658.mjs /out` を実行します（`PORT` 既定 8865）。結果は `result.json` とスクリーンショットに保存され、失敗時は終了コード 1 です。
