# sync565.mjs（BOXP-565）

`sync565.mjs`（BOXP-565）は、同じ本人の 2 端末（storage を共有しない独立した browser context。PC と Pixel 7 縦）で端末間の会話共有を検証します。API は BFF の実コード（`app.ts` / `conversation.ts`）が応答し、Hermes だけをスクリプトが代役します（実行・停止・承認の回数を数える）。

確認項目: (a) 後から開いた端末に発言と返答の履歴が出る、(b) 進行中の依頼が別端末にも作業中・停止ボタンつきで出て返答は各端末 1 回だけ、(c) 別端末から同じ Hermes session で続きを話せる、(d) 同時送信は 1 件だけ実行され本文は失われず自動再送もしない・追跡中の発言は送信待ちから 1 回だけ送られる・同じ受付番号の再送は冪等、(e) 承認待ちは両端末に出るが自動では答えず、片方の回答が 1 回だけ届き古い承認は 409、(f) 別端末から停止でき両端末が停止を表示、(g) 未送信の草稿は共有も送信もされず再読み込みでも再送しない、(h) 進行中に再読み込みしても再送せず続きを追う、(i) 履歴 API が無い古い BFF（404）でもエラーなく会話できる、(j) 保持期限（24 時間）を過ぎた会話は誰も操作しなくても BFF から消え、開いたままの両端末の履歴・吹き出しからも消える（時計は検証側で進める）、(k) 前の依頼を追跡中に別端末が次の依頼を始めても、前の依頼の完了後に次の依頼の進行状態・停止を追える。全項目でページエラーと外部通信が無いことも確かめます。

BFF を `npx tsc -p tsconfig.json --outDir <dir>`（`bff` で実行。`<dir>/node_modules` から `bff/node_modules` を解決できるようにする）でビルドし、Web のビルドを `SITE`（既定 `/site`）の `kohako/` に置いて、`BFF_DIST=<dir> node sync565.mjs /out` を実行します（`PORT` 既定 8815、Playwright 1.56.1）。画像と `result.json` を保存し、失敗時は終了コード 1 です。
