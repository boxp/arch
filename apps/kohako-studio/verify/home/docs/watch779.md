# watch779.mjs（BOXP-779）

`watch779.mjs`（BOXP-779）は BFF を完全にモックし、PC 相当の画面で家の「📺 一緒に見る」（`home.html?watch=1`）を確かめます。共有画面は 1920x1080 の canvas（`captureStream`）、マイクは発振器（`__say(ms)` の間だけ鳴る）に差し替え、認識結果はモックが台本で返します。実際の VRChat・実マイク・実 Whisper・実 Hermes は使いません。

確かめること: 入口は `?watch=1` の時だけ／画面共有は音声を求めない／黙っている間と呼びかけの無い認識文では何も送らず表示もしない／「コハコ」への呼びかけで長辺 1280px の JPEG 1 枚と認識文を `watch: true` で送る（位置は添えない）／考え中の発話は聞き流す／読み上げ OFF でも返事を読み上げ、終われば待機へ戻る／返事前・読み上げ中の「■ やめる」、共有の終了、共有やマイクの拒否で画面とマイクを手放し、届いた返事は読み上げない／聞き取り中に止めると遅れた認識結果では送らない／共有中も入力欄の会話は普段どおりで、その応答待ち中の呼びかけは送らない。

ビルドを `SITE`（既定 `/site`）の `kohako/` に置き、Playwright 1.56.1 で `node watch779.mjs /out` を実行します。失敗時は終了コード 1、結果は `/out/watch779.json` と各場面の画像です。決まりは Obsidian の `Projects/kohako-home/watch-together-spec.md`。
