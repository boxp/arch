# record694.mjs（BOXP-694）

`record694.mjs` は、コハコの腕の動きを実時間の動画（アバターだけ）に録ります。動画を見て確かめる独立レビュー（BOXP-693 と同じ場面・同じ名前）へ渡すためのものです。token 不要の完全な BFF モックで、画面の UI（会話・通知・入力欄・時計）は CSS で隠し、左上に「経過秒 | 場面 [しぐさ・身振り・表情]」だけを出します。会話・通知・秘密は写りません。

実行: Playwright 1.56.1 で `PW_WS=ws://host:port/ node record694.mjs <配備版の home.html の URL | build の dist> <出力先>`。

- 場面: `01` 帰還と基本の待機、`02` 伸び・手を前でそろえる・体を揺らす、`03` 手を振る・口元に手・はにかむ ほか、`04` 頭と視線の待機しぐさ、`05` 会話の身振り 7 種と表情・口パク、`06` 視線追従・なでる・タップ、`07` しぐさの途中の割込み。`ONLY=02,05` で絞れます。
- 各場面を 1280×800 で録り、アバターの範囲（600×720）へ切り抜いて `<出力先>/NN-*.webm` に置きます。切替の区間は、時刻の刻みだけ 4 倍にした `NNx-*-slow4x.webm`（コマは同じ）も作ります。切り抜きと切り出しには ffmpeg（既定は Playwright 同梱、`FFMPEG=` で指定）を使います。
- `recording-meta.json` に、URL、各場面の出来事の時刻（しぐさの開始・終了、割込み）、切り抜きの範囲、スロー版の元の区間、ページのエラーを書きます。ページのエラーがあれば終了コード 1。
- 口パクは、アプリが話している間に毎コマ呼ぶ 2 つ（`stage.setViseme` と `rig.lipSync`）を同じ値で呼んで動かします。音声は流さず、会話の状態（聞く・考える・話す）そのものには入りません。
- 検証メディアは vault に置きません（`/home/boxp/verification-artifacts/<TICKET>/<label>/`）。
