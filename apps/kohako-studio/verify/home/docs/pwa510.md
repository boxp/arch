# pwa510.mjs

### BOXP-510 PWA

`pwa510.mjs` は SITE の `kohako/` に web ビルドを置き、`node pwa510.mjs /out` で実行します。BFF をローカルで完全にモックし、PC / Pixel 7 相当の manifest、アイコン、SW、キャッシュ、オフライン・復帰、Chromium のインストール可能性を検証します。結果は `/out/result.json` に保存し、失敗時は終了コード 1 を返します。Playwright 1.56.1 を使用します。

アイコンの再生成は `cd apps/kohako-studio/web && npm install --no-save --package-lock=false sharp && node scripts/generate-pwa-icons.mjs`。元絵は作画資料 `kohako-exe-navigation-ai-character-sheet-final.png` 左上の胸像で、その無加工の切り出し `scripts/kohako-sheet-face-source.png` から顔を縮小します（ドット絵は使わず、描き直し・生成もしません）。maskable は切り出し全体を使い、目・口・輪郭が中央 80% の円に収まります。帰還演出のメダルも `icon-192-v2.png` を使います。絵を変える時はファイル名の `-v2` を上げてください（端末は古い名前のアイコンを持ち続けます）。
