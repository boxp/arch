# readfollow578.mjs（BOXP-578）

PC と Pixel 7 縦で、長文の読み上げ位置の強調とスクロール、手動操作による停止、ボタンによる再開、読み上げの停止・再開・終了を確認します。BFF はすべてモックし、文字数に応じた無音 WAV を返します。外部通信とページエラーも検査します。

Web をビルドして `SITE` の `kohako/` に置き、Playwright 1.56.1 を利用できる場所から `SITE=<dir> node readfollow578.mjs <出力先>` を実行します。`PORT` の既定は 8812 です。結果とスクリーンショットを出力し、失敗時は終了コード 1 です。
