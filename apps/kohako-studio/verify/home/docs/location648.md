# location648.mjs

`location648.mjs` は BOXP-648 の現在地共有を BFF モックと架空の位置（東京駅付近の公開地点）で検証します。本人の実位置は使いません。PC・スマートフォンの各画面で、既定 OFF・設定で ON（許可済み／ブラウザで拒否／端末が取得できない）・共有停止・「見てきて」の各場合に、送信本文の `location` と画面の状態表示、localStorage/sessionStorage に座標が残らないことを確かめます。ビルドを `SITE`（既定 `/site`）の `kohako/` に配置し、必要に応じて `PORT` と出力ディレクトリ引数を指定して実行します。
