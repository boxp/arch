止める

止めている間は通知を送らず、待ちの依頼は取り消します。解除しても、取り消した依頼は戻りません。

手順（Galaxy Z Fold と Windows 11 の PC）

  1. 各端末で家（コハコの家）を開き、「受信箱」→「通知をONにする」を押す（1回だけ）。
  2. どちらかの端末でこのページを開き、行き先を選んで「通知を送る」。
  3. 試したい端末で通知をタップし、地図が開くかを見る（1タップで地図か、ページを挟んで2タップか）。
  4. もう一方の端末の同じ通知をタップすると「開封済み」と出る（1回だけの確認）。
  5. 期限切れ: 送ってから2分以上待ってタップすると「期限切れ」と出る。
  6. 停止: 送った後に「止める」を押してからタップすると「取り消されています」と出る。止めている間は送れない。最後に「再開する」。
