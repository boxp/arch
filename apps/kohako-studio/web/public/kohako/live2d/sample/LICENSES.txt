Kohako Web Rig Preview — third-party files in this directory (BOXP-441)

Method: PSD2Live's own runtime (.p2lrt + WebAssembly + WebGL). This is NOT the official
Live2D Cubism runtime; no Live2D Cubism Core / SDK file is used or included.

Source: https://github.com/tsunehimatoi/psd2live commit 6fe868a20c7bf12586fa8ce0a05982f099faa865
- p2l.js              : targets/web player, copied unchanged from the CLI "web" export (MIT)
- p2l_runtime.wasm    : runtime/ crate (MIT) rebuilt from source with rustc 1.99.1,
                        cargo build --release --target wasm32-unknown-unknown
                        (129 exported functions identical to upstream's committed build)
- tml.p2lrt           : CLI export "--target p2lrt" of examples/tml/psd-input/tml.psd
                        sample material and outputs released under CC0 1.0 by the PSD2Live examples
                        (https://github.com/tsunehimatoi/psd2live-examples, cases/tml)

The sample character "tml" is not Kohako.
