# BOXP-521: コハコの家のモデルに自然な胸部の揺れを追加する

## 依頼
Owner「モデルの胸が揺れるようにできませんか？」。自然で控えめな胸部の二次動作を、既存素材のまま家の配備モデルへ追加し、実描画で確認する。

## 現状（調査結果）
- 家の配備モデルは全身 v11r（`.p2lrt`、PSD2Live の WASM runtime + WebGL）。
- 胸専用の層・パラメータ・物理は無く、胸は体の層（mesh 26）に焼き込まれている。
- 腕・頭・口などの演技は `web/src/live2d/gesture.ts` の描画直前の頂点変形（`p2l_mesh_vertices` のフック）で足している。

## 方針
- 同じ経路で体の層の胸部の頂点だけを局所ウェイトで動かす。ウェイトは境界で 0 にし、首・襟・袖・腕・髪との接続と原画の輪郭を保つ。
- 揺れの入力は体の層の実際の動き（待機クリップ・身振り・なでの頭追従による体の角度）。ばね・減衰で遅れて追従させ、変位は数 px に制限する。独立した周期ループや全身の拡縮は使わない。
- 静止すると減衰して止まる。新設定「胸の揺れ」（既定 ON）を OFF にしたときと、動きを減らす設定（アプリ設定・OS の reduced-motion）では変位 0。
- 体の層の胸部の頂点密度が粗い場合は、既存の格子（addGrid）方式で胸部だけを細かい格子として重ねる。

## 検証
- 単体テスト: ばねの減衰・遅れ・上限、無効時に 0 になること。
- 実描画の回帰検査（`verify/home/chest521.mjs`）: 身振り中と待機中の胸部の変位（揺れ ON と OFF の画素差）、止めた後の収束、OFF と reduced-motion で差 0、顔・首・腕の領域に差が出ないこと。修正前の main では失敗し、修正後に合格することを確かめる。連続フレームを保存する。
- 非退行: 既存の lookfollow516 / petvisible / mouthpet / touchgate / arms510。
- 通常 CI → codex review（P0/P1 なし）→ merge → GitOps 配備 → 配備物で PC / Pixel 7 の連続フレームを旧版と比べる。
