# BOXP-476: Studio の表情・動作の拡充

Web リグ（kohako-full-v11r）に、発話内容に合わせた表情と腕・体の動作を足す。

- 受入済みの通常表示は変えず、`?acting=1` のときだけ有効にする比較版として配備する。
- OpenAmika の制御（文単位の感情適用、再生開始での同期、flush による割込み）は考え方のみ移植する。Pixi / Cubism の描画系は流用しない。
- 感情判定は応答文のルールベース。別 LLM や第二の記憶は追加しない。
- 新規画像生成・追加費用はなし。既存リグの頂点出力を描画直前に変形する（`src/live2d/gesture.ts`）。

## 手順
1. 手動比較（`/kohako/live2d.html?acting=1`）で表情・動作を確認する。
2. Studio（`/kohako/studio.html?acting=1`）で実 Hermes 会話に連動させ、遷移・停止・割込みを試験する。
3. 本人確認のあと、既定への反映を別途判断する。

## 既知の限界
- 腕が 1 mesh のため肘の折り曲げに皺が残る。解消には腕層の分割（再 rig）が要る。
- 実機 GPU の見え方は未検証。

## TD-06: 案X ケープの層分け試作（2026-11-10）

- 目的: 直前の不合格試作 arm-band-3e388e8 で「黒い上腕がケープの上に貼り付いた帯」に見えた点を、生成なしで前後関係から直す（制止だけ、1 回）。

## TD-06: Y' 段階① 腕セットの切替の事前確認（2026-11-10）

- 目的: 一般的な Live2D の腕 A/B と同じく、制止を変形で作らず、動作の始まりに 0.25 秒のフェードで既存比較版の制止の腕へ差し替えたときの見え方を、生成なしで確かめる（切替の受入性の判定。肘の自然さは対象外）。
- 試作: commit 9a5842ef（タグ `kohako-studio-candidate/arm-fade-9a5842e`）。裏に待機の腕（元のメッシュ・テクスチャの複製）を残し、背景の透けを 0.15 以下に抑える。解除と割込みは今の腕を待機の腕へフェードアウトしてから切り替える。
- 独立実操作判定: 開始・解除のフェード、残留、顔と通常表示の不変は合。制止→照れの割込みで手が腹の前を横切るため不合格。取り決めどおり、制止用の部品の生成（段階②）はしない。
- 候補 `arm-fade-9a5842e` として状態と問題点を付けて候補一覧へ追加する。腕のコードは main に入れない。
