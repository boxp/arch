# BOXP-476: Studio の表情・動作の拡充

Web リグ（kohako-full-v11r）に、発話内容に合わせた表情と腕・体の動作を足す。

- 受入済みの通常表示は変えず、`?acting=1` のときだけ有効にする比較版として配備する。
- OpenAmika の制御（文単位の感情適用、再生開始での同期、flush による割込み）は考え方のみ移植する。Pixi / Cubism の描画系は流用しない。
- 感情判定は応答文のルールベース。別 LLM や第二の記憶は追加しない。
- 新規画像生成・追加費用はなし。既存リグの頂点出力を描画直前に変形する（`src/live2d/gesture.ts`）。

## 手順
1. 手動比較（`/kohako/live2d.html?acting=1`）で表情・動作を確認する。
2. Studio（`/kohako/studio.html?acting=1`）で実 Hermes 会話に連動させ、遷移・停止・割込みを試験する。
3. 本人確認のあと、既定への反映を別途判断する。

## 既知の限界
- 腕が 1 mesh のため肘の折り曲げに皺が残る。解消には腕層の分割（再 rig）が要る。
- 実機 GPU の見え方は未検証。

## TD-06: 連続した腕の絵と帯メッシュの試作（照れ・制止のみ）
- 4 枚の板（前腕・上腕・曲げ用小手・肘袖）を剛体で回す方式では肘をまたぐ絵が無く、継ぎ目が移るだけだった。
- 肩〜手首を 1 枚で描いた腕の素材（`acting/arm-band.png`、画像生成 1 回）を帯状メッシュにし、上腕と前腕の 2 本の骨の角度を肘のまわりで混ぜて曲げる（`bandPoint`）。
- 対象は `?acting=1` の照れ・制止だけ。挨拶・案内・喜びは従来のまま。通常表示とモデルファイルは変えない。
- 戻し方: この変更を revert すると従来の板の腕に戻る（素材は追加のみ）。
- 合否は独立レビュー役が候補を自分で起動・操作して判定する（一本の腕/肘の曲がり/照れの演技/切替の跳び・二重なし/顔と通常表示の不変）。
- 結果（4601716c）: 独立実操作レビューで不合格。BOXP-489 の見直しで、曲げ位置が金の輪の直前にあったことと、生成素材の小手が軸に垂直な「筒の口」の輪で正本/v11r の V 字の縁と形が違うことが原因と分かった。

## TD-06/07 段階①: 制止だけを生成なしで直す（Owner A）
- 帯は黒い袖の部分だけ使う。曲げは素材の肘のしわ（y=420）に置き、素材の金の輪の手前（y=504）で切る。
- 前腕は v11r の V 字の縁の小手（休止と同じ絵）をそのまま重ね、黒い袖がその縁の中へ入る並び「肩の装甲→黒い上腕→黒い肘→金の縁→紫」にする。動き始めと戻りで小手の形が変わらない。
- 上腕の上端は肩口で細くし、素材の上端の切り口だけ短くぼかす（`arm-band.png` の加工、生成なし）。
- 元の手と手の素材は中点で 0/1 に切り替え、半透明の二重の手を作らない（#14733 から `handSwap` だけ持ち込み。#14733 の照れの変更は入れない）。
- 照れは帯を使わず従来の比較版のまま。照れ専用の遠近の腕は、制止が独立実操作判定で合格した場合だけ別段階で試作する。
