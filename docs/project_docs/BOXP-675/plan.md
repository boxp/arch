# BOXP-675 計画

- 現行 localllm のケース一覧と全 suite を固定し、2 shard に分けて重複・欠落を検証する。未指定時は全ケースを実行し、不正な shard 設定は開始前に失敗させる。
- matrix の同時実行数を増やし、novel-board を独立グループに移す。既存の集約ゲートと fail-fast 無効を維持する。
- 各 shard の一時状態とサーバーを隔離し、2 shard を同時実行してケース一覧、失敗伝播、対象テストを検証する。
- 変更は CI の有限なスケジューリングと在庫に限られるため、Lean の抽象モデルを追加せず実際の設定と実行を直接検査する。実測と制約を evidence.md に記録する。
