# BOXP-578: 読み上げ中は読んでいる箇所へ自動スクロールし手動操作で追従を止める

## 目的
コハコの家で長い返答を読み上げている間、今読んでいる箇所を画面が追い、本人が手でスクロールしたら位置を奪わずに追従を止める。追従へ戻る操作を分かりやすく出す。

## 取得できる再生位置（精度と限界）
- コハクの声（家サーバー TTS, `voice.ts`）: 再生単位は「グループ」（1〜複数の文片、最大約 120〜160 字）。分かるのはグループの再生開始時刻と音声長のみ。グループ内は文字数に比例した線形補間で推定するため、文字単位の正確さはない（間・読み方の差でずれる）。グループの切り替わり時点では正確。
- 端末の声（Web Speech）: `onBoundary` の `charIndex` が出る端末ではその位置を使い、出ない端末では文字数から経過時間を推定する。強調はどちらも文片単位。
- 本文対応: 読み上げ用平文（Markdown 記号除去済み）を表示 DOM のテキストへ空白無視で順に照合。照合できない片（表・コード等で文字が変わる箇所）は前後から比例推定。

## 設計
- 新規 `web/src/home/readfollow.ts`: 照合・補間・追従状態の純粋関数と DOM 補助（Range, CSS Custom Highlight API で強調、未対応環境はスクロールのみ）。
- 追従先: PC/横画面は吹き出し（内部スクロール）、縦画面はチャット欄（吹き出しが中に入る）。
- 利用者のスクロール操作（ホイール・指でなぞる・上下キー・つまみ操作）で追従停止。プログラムからのスクロールは操作とみなさない。
- 停止中は「読んでいる所へ戻る」ボタンを表示。押すと即座に現在位置へスクロールし追従再開。新しい返答・「続きから読む」でも追従を再開。
- 停止/一時停止/再開/読み直し、新着スクロール（BOXP-563）、口パク、会話入力は既存の挙動を保つ。
