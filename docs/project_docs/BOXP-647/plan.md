# BOXP-647 読み上げなし時の返答表示

## 原因と方式

返答後60秒で場面が `relax` に移り、PC・横向きの吹き出しはCSSで隠れる。縦スマホは会話ログ側の表示規則があり端末間で差があった。長文の黙読時間を文字数から決める方式では読み返しを保証できないため、実際に読み上げを開始しない返答は時間で隠さない。

`deliver` で音声開始の有無を判定し、非読み上げ返答に保持状態を付ける。場面自体は通常どおりくつろぎへ移る。保持中は吹き出しを表示し、大きな時計と利用枠が重ならないようにする。ヘッダーの時計は残る。`setBubble` による本文の差し替え（次の依頼、通知、確認、ふれあい等）で保持を解除する。履歴の保存期間・承認・送信待ち・入力仕様は変更しない。設定のON/OFFだけでは、現在の本文を別の返答として扱わない。
