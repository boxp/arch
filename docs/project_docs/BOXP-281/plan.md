# BOXP-281: ひとはこさん hero を勇ましさ偏重から原典のキャラクター性が伝わるイラストへ修正

対象: `apps/hitohako`（stage: hitohako-stage.b0xp.io のみ。本番・共有インフラ・認証 policy は変更しない）

## 背景

BOXP-280 で差し替えた hero（薙刀を両手で振りかぶる跳躍構図）は、強い視線と開いた四肢で「勇ましい戦闘キャラ」の印象が主役になり、Owner レビューで「男らしすぎる。ひとはこさんのキャラクター性が分かる絵に」と修正依頼が入った。

## 方針

1. **キャラクター性の表現**（原典優先）
   - 原典設定「育ちが良く包容力のある、清楚で優しい印象。ここぞという時には芯の強い一面」に合わせ、穏やかな微笑・自然な肩と手指・しなやかな所作で表現する。
   - 薙刀は設定どおり持たせるが、構えず傍らに立てて添える程度に留め、視覚の主役にしない。強い踏み込み・睨み・武器の威圧は使わない。
   - 露出増・体形の誇張・幼児化で「女性らしさ」を代替しない。一般的な戦闘少女や別人にしない。
2. **同一性・衣装**: 黒髪ロング + 左右の三つ編み、碧眼、桜の髪飾り、桜柄と金縁の紫着物トップス、肩当て、帯リボンと長いサッシュ、指ぬきグローブ、黒×紫ブーツ、紫金の薙刀。
3. **大きさ・軽やかさの維持**: 髪・帯リボン・サッシュのなびきで静止画としての軽やかな動きを出す。表示サイズ（desktop `min(800px, 82dvh)` / mobile `min(560px, 52dvh)`）と `<picture>` + preload の構成は BOXP-280 のまま。
4. **制作**: Nano Banana Pro（`gemini-3-pro-image`, 2K, 3:4, 緑背景）で複数候補を生成し、原典と目視比較して採用。`scripts/make-hero.py` で透過化（ドット絵化・減色・nearest 拡大なし）。
5. **不変更**: 配信アーカイブ 6 件・章順・既反映文言・STG 記録・仲間・他キャラ・静的表示（点滅/走査線/動的演出なし）。

## 検証

- `npm run build`、Playwright（Docker 公式イメージ）で desktop / mobile の hero 表示（顔・衣装・表情の読み取り、文字/CTA、切れ・余白、横はみ出し、console error）。
- 実 stage（Cloudflare Access 本人限定）は deploy 成功までを確認し、本人ログイン後の表示確認を依頼する。

## Rollback

PR を `git revert` して main に merge すると BOXP-280 の hero（c9973c6e 相当）に戻る。
