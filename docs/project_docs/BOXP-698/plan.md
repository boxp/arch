# BOXP-698: コハコが待機中に浮く椅子へちょこんと座る（試作候補）

## 目的

家の画面のコハコが、待機中に気分で宙に浮く簡素な椅子へ腰かける。まず本人だけが見られる比較候補として、絵と実時間の動きを見られる形にする。通常版への昇格と見た目の合否は本人が決める。

## 調べて分かったこと

- モデル `kohako-full-v11r` は、脚（層 29・30）、足（27・28）、上着の裾（24・25）が胴（26）と別のメッシュ。腕と同じく、描画直前の頂点変形で形を変えられる。
- 家の画面の待機しぐさ（BOXP-605）は `web/src/home/idle.ts` が決め、`live2d/gesture.ts` の stage が描く。座る動きは、これとは別の層として足せる。
- 試作は通常版を上書きせず、タグ固定の候補（`/kohako/candidates/<id>/`）として配る決まりがある。候補の build には家の画面（home.html）も含まれ、API は nginx が通常の BFF へ書き換える。

## 方式

1. **座り姿は新しい絵を使わない。** 正面向きに腰かけると太ももは手前へ向かって短く見えるので、脚の「付け根〜ひざ」の区間だけを縦に縮め、ひざから下をそのぶん持ち上げる。裾は縦に縮めて外へ広げ、座面に載せる。腕・上半身・顔・髪は変えない。
2. **椅子はコードで描く**（背もたれの無い円盤の腰かけと光の輪）。画像の生成・購入・新しい権限は使わない。モデルのいちばん奥へ 1 枚足す。
3. **座る・立つは別の状態機械**（立ち姿 → 座る途中 → 座っている → 立つ途中）。椅子が先に現れてから腰を下ろし、立ち切ってから椅子が消える。
4. **既存の動きを守る。** 座っていても待機しぐさ・視線追従・なでる・タップ・腕のフェードは上半身にそのまま出る。会話・確認待ち・失敗・現場・録音などが始まったら、応答と並行して 0.4 秒で立つ（応答を待たせない）。非表示ではすぐ立ち姿。設定「待機中のしぐさ」OFF、「動きを減らす」では座らない。座っていない間の描画は変更前と画素一致。
5. **通常版は変えない。** 座る動きのコードは候補のタグ `kohako-studio-candidate/<id>` にだけ置く。main へ入れるのは、候補の登録（`candidates.json`）、一覧から家の画面へ入るリンク、検証スクリプトと説明だけ。

## 仕様・テスト

- 仕様（案）: vault `Projects/kohako-home/seat-spec.md`（状態遷移図つき）。
- 単体テスト（候補の版）: `web/src/home/seat.test.ts`、`web/src/live2d/seat.test.ts`。期待値は仕様の数字から書き、先に失敗を確認した。
- Lean のモデルは作らない: 規則は時間の曲線についての条件（いつも椅子の濃さ ≥ 座り具合、偽になって 0.4 秒で 0 など）で、離散の状態表を写しても確かめられない。代わりに乱数の操作列 300 本を全コマで確かめる。
- 実ブラウザ: `verify/home/seat698.mjs`（規則の確認・コマの一覧・実時間の録画）。

## 手順

1. 調査（済）
2. 仕様（案）→ テスト → 実装（候補の版）
3. 手元 build を実ブラウザで確認（規則・コマ・実時間の動画）
4. 候補のタグを push、`candidates.json` へ登録する PR
5. merge → image build → 配備 → 配備版の候補 URL で確認
6. vault の Projects 正本・平易な入口へ納品（本人の確認方法、正直な弱点）

## 範囲外

- 通常版の家の画面へ座る動きを入れること（本人の判断の後）。
- 画像の生成・購入・従量 API・新しい権限・モデルの作り直し。
