# BOXP-506: コハコの家の視覚コンテンツ領域（地図・HTML図表）

## 目的
会話を続けたまま、返答に結び付いた地図や図表を開閉できる領域を kohako-home に加える。

## 構造化された受渡し
- BFF が Hermes へ渡す instructions に、返答末尾へ 1 つまで置ける ```` ```kohako-view ```` JSON ブロックの書式を追加する。
- BFF（`bff/src/views.ts`）がブロックを抜き出して厳格に検証し、本文（吹き出し・読み上げ）から除去して `views` として返す。不正なブロックは捨て、本文から除去する。
- 種類
  - `map`: 目的地の名前・住所（任意で出発地・移動手段）。BFF で目的地を検索し、家側で OpenStreetMap の地図を表示する。Google Maps URLs（公式・キー不要）は外部リンクとして残す。
  - `usage`: 数値を持たない。家が既存 `/kohako/api/v1/status`（BOXP-504）の実データで棒グラフを描く（観測時刻・共有/専用・未提供・鮮度を表示）。
  - `html`: モデルが作った HTML。未信頼として家の側で script・meta・リンク先・イベント属性など遷移や外部参照につながる要素と属性を除去し、`sandbox=""`（スクリプト・同一 origin・遷移を許さない）の iframe に srcdoc で表示し、先頭に `script-src 'none'` と通信を全部禁じる CSP を置く（iframe 自身の遷移は CSP では止められないため、JavaScript は実行させない）。

## 地図の制約
- Google Maps Embed API はキーと新規契約が必要なため使用せず、直接 iframe や非公式の output=embed も使わない。
- BFF は目的地の住所・名称・丁目の順に Nominatim で検索する。出発地は送らず、固有 User-Agent、全体で毎秒 1 回以下、24 時間のメモリーキャッシュと 4 秒のタイムアウトを設ける。
- 家は検索結果から OpenStreetMap 公式の埋め込み URL を組み立て、地図を自動表示する。丁目のみの結果はマーカーなしで概略位置を示し、検索できない場合は外部リンクを示す。
- Google Maps URLs の外部リンクは補助として残し、開くと目的地（選択時は出発地も）が Google に送られることを明示する。

## 安全境界
- HTML 図表の iframe は opaque origin とし、通信・フォーム・ポップアップ・上位遷移を禁止する。OSM iframe は同一 origin とスクリプトのみ許可し、フォーム・ポップアップ・上位遷移は許可しない。親は iframe からのメッセージを受け取らない。
- リンクは `https://www.google.com/maps/...` に限り家側で組み立てる。モデルが書いた URL はそのまま使わない。
- 住所や経路 URL はサーバーログや公開成果物に保存しない。検証には合成の出発地を使う。

## 画面
- 地図は自動表示し、結果カードに再表示用の「地図を表示」と「グラフを開く」「図を開く」を出す。表示領域は PC では右側、スマホでは入力欄の上の下部シートとし、キャラクター・吹き出し・入力・停止・承認を覆わない。閉じるボタンと Esc で閉じる。

## 検証
- 単体: views の抽出と検証（陰性: 不正 JSON、未許可の種類、`javascript:`、長すぎる値）、Maps URL の組み立て、sandbox と CSP の属性。
- 実ブラウザ: PC とスマホで描画と重なりを確認する。悪意ある HTML（親への参照、fetch、top 遷移、cookie）が失敗すること、未認証の拒否、会話・停止・承認・ふれあいの非退行も確認する。
- 配備後: 検証用会話で実 Hermes から地図とグラフを開く。
