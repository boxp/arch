全体計画は `plan.md`（boxp/arch#15287・boxp/lolice#1282）。本書は段2の arch 側だけを扱う。

## 現場（visit）
- 入口: 家の「見てきて」ボタン、会話の合言葉（プラグイン / 見てきて 等の完全一致）、警告通知（alertmanager）への「見てきて」。いずれも本人だけ。
- Hermes session は `kohako-visit-<時刻><乱数>`（家の会話とは別）。ナビログは各 visit session の最後の発言を「現場の報告」として写す。
- 実行前の遮断は Hermes の kohako-g2-context ゲート（boxp/lolice#1284）。BFF は開始通知を見て Grafana 以外・20回超・180秒超で停止する二重の守り（開始後の停止であり、実行前の強制ではない）。
- 報告は「見た時刻」+4行（見た物 / 分かった事 / 分からなかった事 / 次に要る事）。BFF が止めた場合は BFF が作った報告を出す（ナビログには写らない）。
- 操作・書き込み用の道具・新しい権限は無し。

## 家へ戻る演出（TD-01）
- 既存のドット絵（c48v6）と動く姿だけを使い、画像は作らない。CSS（scale / translate）のみで明滅しない。
- 段階は実際の処理状態で決める: 動く姿の読み込み中＝戻っている途中（光の柱の中でドット絵が組み上がる）、現場の実行中＝出ている（柱の中で薄く表示）、読み込み完了・現場から戻った直後＝0.9秒だけ着地、その後は通常。
- 入力・送信は一切待たせない。「動きを減らす」/ OS の reduced-motion では柱を静止表示するだけ。
